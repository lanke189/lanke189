# 可安装的 AI 开发 Skills

## ai-dev-workflow

[查看 Skill](ai-dev-workflow/SKILL.md)：按需求、UI、技术方案、开发、验收和发布推进 AI 辅助软件开发。包含原规范、六份文档模板和项目 `AGENTS.md` 示例。

安装到所选、支持 Agent Skills 的 AI 编程工具的个人 Skills 目录（需要 Node.js）：

```bash
npx skills add lanke189/lanke189 -g
```

安装时按提示选择所用工具。开启新会话后，通过该工具的 Skill 列表或调用语法使用 `ai-dev-workflow`。项目级规则可参考 Skill 中的 `AGENTS.md.example`，按所用工具的规则文件格式调整。
